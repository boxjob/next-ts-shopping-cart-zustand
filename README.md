# 🧩 Next.js + TypeScript + Zustand + Tailwind + React Icons

Este projeto é uma aplicação **Next.js** construída com **TypeScript**, **Zustand** para gerenciamento de estado, **TailwindCSS** para estilização e **React Icons** para ícones.  
Conta também com persistência de estado no **localStorage** e um hook customizado para controle de montagem do cliente.


## 🚀 Tecnologias utilizadas

- **Next.js** — Framework React para SSR e SSG  
- **TypeScript** — Tipagem estática e segurança no código  
- **Zustand** — Gerenciamento de estado simples e performático  
- **Tailwind CSS** — Estilização utilitária e responsiva  
- **React Icons** — Biblioteca de ícones popular e flexível  


## ⚙️ Instalação e execução

### Instale as dependências

npm install
# ou
yarn install

### Execute o servidor de desenvolvimento

npm run dev
# ou
yarn dev

### Acesse no navegador

http://localhost:3000
